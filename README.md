# Titanic Survival Prediction App

## About the Project
This project predicts the survival probability of a passenger on the Titanic using Machine Learning.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Streamlit
- Joblib

## Machine Learning Model
A Decision Tree Classifier was trained using the Titanic dataset.

## Features
- Select passenger ticket class
- Choose passenger gender
- Enter passenger age
- Enter ticket fare
- View estimated survival probability

## Model Accuracy
79.72%

1. Install the required packages:
   `pip install -r requirements.txt`
2. Run the application:
   `streamlit run app.py`
